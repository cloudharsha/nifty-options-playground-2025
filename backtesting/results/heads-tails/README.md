# Heads & Tails results

Random-entry controls. A coin flip decides direction; everything else — sizing,
stops, costs — matches the signal-based strategies.

These exist to keep the rest of the repo honest. A strategy that does not clearly
beat these numbers on the same instrument and the same costs has not shown that
its signal contributes anything.

Produced by [`../../python/heads-tails/`](../../python/heads-tails/).
Indexed in [heads-tails.md](../../docs/results/heads-tails.md).

The two grid `_daywise.csv` dumps are not tracked in git (67 MB); re-run the grid
scripts to regenerate them.
