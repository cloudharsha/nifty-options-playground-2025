# Intraday straddle results

ATM straddles opened and closed within a single session, on both NIFTY and
SENSEX, weekly and monthly expiries. Entry applies a CE/PE balance filter; stops
are either independent per leg or joint across both.

Produced by [`../../python/intraday-straddle/`](../../python/intraday-straddle/).
Indexed in [intraday-straddle.md](../../docs/results/intraday-straddle.md).

These runs previously lived in a folder named `legacy-3`, which was misleading —
they come from currently active scripts.
